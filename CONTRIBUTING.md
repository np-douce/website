# Contributing to NP-douce/website

Thanks for your interest in contributing! We welcome improvements to code, documentation, examples, and the website demo.

Quick start

1. Fork the repo and clone it locally:
   git clone https://github.com/np-douce/website.git
2. The app is a static site. Open `index.html` in a browser to run the demo locally.
3. Make small, focused changes on a feature branch named `feature/<short-description>` or `fix/<short-description>`.

Workflow

- Open an issue before starting larger work so maintainers can provide guidance.
- For very small fixes (typos, docs), you may open a PR directly.
- Create a branch from the repo `main` branch and push your branch to your fork.

Pull request expectations

Please include in your PR:
- A short summary of what changed and why.
- Tests or screenshots for UI changes, when applicable.
- A link to the related issue (if any).

PR checklist

- [ ] PR description is clear and links to an issue (if relevant).
- [ ] Changes are small, with a focused scope.
- [ ] Documentation updated when behavior changes.
- [ ] Linter or CI passes (if applicable).

Coding style

- Keep changes minimal and well-explained.
- Use clear commit messages.

Support

If you need help picking a task, see the `.github/GOOD_FIRST_ISSUES.md` file, or open an issue and label it `help wanted`/`good first issue`.

Thanks — contributors make this project better!
